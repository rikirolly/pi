## [Unreleased]

### Added

- Initial implementation of Mem0 API client
- `addMemories` - Add memories from conversation messages
- `searchMemories` - Search memories with semantic and keyword matching
- `getMemories` - Get all memories for an entity
- `getMemory` - Get a specific memory by ID
- `updateMemory` - Update a specific memory
- `deleteMemory` - Delete a specific memory
- `getEvent` - Get event status for async operations
- `waitForEvent` - Wait for async operations to complete
- `addMemoriesAndWait` - Add memories and wait for completion
